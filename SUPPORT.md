## Before You Ask

Aaroh has no application code, no installation procedure, and no running system. If you are looking for a way to install or use Aaroh, there isn't one yet — that is expected, not a bug.

Start with [README.md](./README.md), which describes exactly what does and does not exist.

## GitHub Issues

If the documentation does not answer your question, open an issue using the appropriate template:

- **Question:** [question template](./.github/ISSUE_TEMPLATE/question.md)
- **Bug:** [bug report template](./.github/ISSUE_TEMPLATE/bug_report.md) — currently applies to documentation and repository configuration only
- **Feature or product idea:** [feature request template](./.github/ISSUE_TEMPLATE/feature_request.md)

Product and design questions are especially welcome at this stage, because nothing has been decided yet and input still changes the outcome.

---

## Security Issues

Do not open a public issue. Follow [SECURITY.md](./SECURITY.md).
